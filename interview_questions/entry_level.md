# Interview Questions - Entry Level

## Networking & Web Fundamentals

- Describe the life-cycle of a web browser request
	- i.e. a user opens up the web browser, types in `google.com` and hits enter. What happens next?
	- Describe what happens at the the different networking layers
- Describe at a high-level the TLS handshake
- Describe the importance of HTTPS as opposed to HTTP
- Describe DNS
- What is a cookie?
	- What are ways you can secure them?

## Security Fundamentals

- What is the CIA triad?
	- Describe one security control for each
- What is defense-in-depth?
	- Give an example of defense-in-depth in practice
- Compare and contrast symmetric and asymmetric cryptography
	- How can they be used together?
- Compare and contrast encryption and cryptographic hashing
- Compare and contrast cryptographic hash algorithms vs password hash algorithms
- Describe AAA
- What is the difference between Authentication (Authn) and Authorization (Authz)
- Describe the principle of least privilege
- What is the difference between horizontal and vertical privilege escalation?
- What are the three types of authentication?
- What is multi-factor or two-factor authentication?

## Vulnerabilities

- Describe a specific vulnerability class
	- What is it?
	- How do you prevent it?
	- Examples:
		- XSS
		- SQLi
		- CSRF
		- SSRF
		- etc
- Describe a time you found a software vulnerability

## Application Security Testing

- Describe the following:
	- Secrets scanning
	- SAST
	- DAST
- Compare and contrast SAST and DAST
- Compare and contrast SCA and SAST

## Defensive Programming

- How would you perform input validation on different data types:
	- Database ID
	- Phone number
	- Free-form text
	- etc
- Compare and contrast input validation, sanitization, and output encoding
	- How should they be used?
	- What type of attacks can they prevent?
- What are some things that you would look for from a security perspective when reviewing code?

## Misc

- What is something you want to learn more about?
- What type of work does not interest you?
- What are some ways that you could use an LLM to assist in your daily work?
